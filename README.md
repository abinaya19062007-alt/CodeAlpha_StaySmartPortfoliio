# StaySmart — Intelligent Hotel Reservation & Stay Planner

A Java Swing hotel reservation simulator designed as a portfolio project.

## Core reservation features
- Room availability
- Guest details
- Room selection
- Booking confirmation
- Cancellation
- Automatic bill calculation
- CSV booking report

## Additional features
- Preference-based smart room matching
- Budget-aware recommendations
- Eco score for rooms
- Occupancy dashboard
- Booking activity log
- Distinct hospitality-focused UI

## Technologies
Java, OOP, Java Swing, Collections, File I/O, CSV.

## Run
Open `src/StaySmartApp.java` in VS Code and choose **Run Java**.

This is an educational simulation, not a real hotel inventory or payment system.
